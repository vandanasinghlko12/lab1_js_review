## How did you approach creating more flexible functions with parameters
I first understood the requirements of each task, identified the parameters needed, and then developed the logic step by step. I used concepts like conditional statements, string methods, arithmetic operations, and input validation depending on the problem. ## What challenges did you face while incorporating conditional logic in your functions?

How to use conditional operators correctly, especially when checking multiple conditions using && and ||.Initially, I was confused about where to place the conditions and how they would affect the function's output. By testing different inputs and debugging my code, I gradually improved my understanding of conditional logic.

## How does refactoring improve the readability and maintainability of your code?
Refactoring helped me improve my existing function by adding a new parameter for discount without changing the overall structure of the code. I updated the logic to handle both scenarios: when a discount is provided and when it is not provided.
